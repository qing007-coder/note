# EfficientNet-B3：结构与面试复习

> 以提供的 **RT-1 本地 TF-EfficientNet-B3 源码**为准；输入 `[B,3,300,300]`，维度顺序为 `[B,C,H,W]`。
>
> **核心思路**：用 MBConv 降低计算开销，用 SE 调整通道的重要性，再通过复合缩放平衡网络深度、宽度和输入分辨率。

## 1. 整体结构与维度变化

```text
输入 → Stem 卷积 → 7 个 Stage（共 26 个块）→ 1×1 Head → 空间特征图
```

| 阶段 | 模块 | 重复次数 | 首块 stride | 输出 `[B,C,H,W]` |
|---|---|---:|---:|---|
| 输入 | RGB 图像 | — | — | `[B,3,300,300]` |
| Stem | 普通 3×3 Conv + BN + SiLU | 1 | 2 | `[B,40,150,150]` |
| Stage 1 | MBConv1，3×3（源码名 `DepthwiseSeparableBlock`） | 2 | 1 | `[B,24,150,150]` |
| Stage 2 | MBConv6，3×3 | 3 | 2 | `[B,32,75,75]` |
| Stage 3 | MBConv6，5×5 | 3 | 2 | `[B,48,38,38]` |
| Stage 4 | MBConv6，3×3 | 5 | 2 | `[B,96,19,19]` |
| Stage 5 | MBConv6，5×5 | 5 | 1 | `[B,136,19,19]` |
| Stage 6 | MBConv6，5×5 | 6 | 2 | `[B,232,10,10]` |
| Stage 7 | MBConv6，3×3 | 2 | 1 | `[B,384,10,10]` |
| Head | 普通 1×1 Conv + BN + SiLU | 1 | 1 | `[B,1536,10,10]` |

- **一个 Stage 是多个块，不是一个卷积层。** 同一 Stage 只有首块可能下采样，其余块 stride 都为 1，输入、输出通道均为该 Stage 的输出通道数。
- 表中的 3×3 / 5×5 指块内的 **Depthwise 卷积核**；MBConv6 的 6 指扩展倍数，不是重复次数。
- 源码使用 TensorFlow **SAME padding**：输出空间尺寸为 `ceil(H/stride)`，所以 `75→38`、`19→10`。偶数尺寸下 stride=2 时，padding 可能不对称。
- 总下采样倍数为 32：任意输入 `[B,3,H,W]` → `[B,1536,ceil(H/32),ceil(W/32)]`。

## 2. MBConv 内部：先扩展，再提取，再投影

以 **Stage 3 的第一个 MBConv6** 为例：输入 32 通道，输出 48 通道，kernel=5、stride=2。

```text
输入                                      [B, 32,75,75]
  ↓ 1×1 Conv 扩展通道 + BN + SiLU
                                          [B,192,75,75]  ← 32×6
  ↓ 5×5 Depthwise Conv，stride=2 + BN + SiLU
                                          [B,192,38,38]  ← 只做空间提取
  ↓ SE 通道重加权
                                          [B,192,38,38]  ← 形状不变
  ↓ 1×1 Conv 投影 + BN，无激活
输出                                      [B, 48,38,38]
```

**这个块没有残差连接**，因为尺寸和通道都发生了变化。同 Stage 后两个块是 `48→288→48`，空间尺寸保持 `38×38`，可以使用残差。

**Stage 1 的区别**：扩展倍数为 1，直接省略开头的升维卷积：`Depthwise → BN+SiLU → SE → 1×1 投影 → BN`。

### SE 里面发生了什么？

对上面 `[B,192,38,38]` 的特征：

```text
全局平均池化 → [B,192,1,1]
1×1 Conv + SiLU → [B,8,1,1]
1×1 Conv + Sigmoid → [B,192,1,1]
与原特征逐通道相乘 → [B,192,38,38]
```

**注意源码细节**：SE 的压缩通道数按块输入计算：`round(Cin×0.25)`，这里为 `32×0.25=8`，不是按扩展后的 192 计算。权重在空间维广播，每个通道共用一个权重。

## 3. 面试重点：为什么这么设计？

| 常见问题 | 核心回答 |
|---|---|
| 为什么用 Depthwise + 1×1 卷积？ | **把空间提取和通道混合分开**：Depthwise 每个通道独立卷积，1×1 卷积负责通道间的信息交互，降低计算开销。 |
| 为什么先升维？ | Depthwise 本身不混合通道，先通过 1×1 卷积构造更丰富的通道组合，再做空间提取，最后压缩，平衡表达能力和计算量。 |
| 为什么叫倒残差 / 倒置瓶颈？ | 传统 ResNet bottleneck 是“宽→窄→宽”；MBConv 是“窄→宽→窄”，残差连接在较窄的输入和输出之间。 |
| 为什么投影后不加激活？ | 这是**线性瓶颈**：在较窄的表示上再施加强非线性，可能损失信息。源码末尾保留 BN，关闭 SiLU。 |
| 为什么加 SE？ | 根据整张特征图的统计，自适应调整各通道的贡献；让通道选择随输入变化。SE 是通道注意力，不会生成每个位置独立的空间权重。 |
| 什么时候加残差？ | 仅当 `stride=1 且 Cin=Cout`，执行 `y=x+F(x)`，帮助梯度传播和特征保留；这份源码不额外用投影支路凑齐维度。 |
| SiLU 是什么？ | `SiLU(x)=x·sigmoid(x)`，等于 β=1 的 Swish。平滑且保留部分负值，是 EfficientNet 使用的激活函数。 |
| DropPath 有什么用？ | 训练时按样本随机丢弃残差分支，做正则化；推理时保留分支。此源码仅在有残差的块中调用，且默认 `drop_path_rate=0`。 |

**计算量怎么解释？** 对相同空间尺寸、输入 C 通道、输出 C′ 通道，忽略 BN / 激活：

```text
普通 k×k 卷积：                  H×W×k²×C×C′
Depthwise k×k + Pointwise 1×1：  H×W×(k²×C + C×C′)
```

后者与前者的比值为 `1/C′ + 1/k²`。**完整 MBConv 还包括扩展卷积和 SE**，不能直接把这个比值当成整个块的节省比例；实际速度还受硬件和访存影响。

## 4. EfficientNet 的核心贡献：复合缩放

**不只加深网络，而是协调增加深度、宽度和输入分辨率。**

- **深度 d**：增加块的重复次数，增强层级特征提取。
- **宽度 w**：增加通道数，增强特征表达能力。
- **分辨率 r**：提高输入尺寸，保留更多图像细节。

论文用统一系数 φ 控制三者：`d=α^φ，w=β^φ，r=γ^φ`。卷积计算量近似按 `d×w²×r²` 增长，因此选择满足 `α×β²×γ²≈2` 的系数，让 φ 每增加 1 时计算预算大致翻倍。

**为什么要一起调整？** 更高分辨率提供更多细节，也需要相应的网络容量去处理；只增加某一个维度，收益可能逐渐饱和。B3 是缩放后的具体配置，源码已经固定了通道数和重复次数，不会在前向时动态缩放。

## 5. 这份源码与分类网络的区别

- **这份 RT-1 特征提取实现**：保留空间布局，输出 `[B,1536,10,10]`；Head 指最后的 1×1 卷积，不是分类器。
- **标准 ImageNet 分类 B3**：之后还会做全局平均池化 → `[B,1536]` → Dropout → 全连接 → `[B,1000]`。
- 保留空间特征便于后续模块提取视觉 Token；当前文件只实现 CNN 主干，没有实现 RT-1 的语言条件 FiLM 或 TokenLearner。

**面试速记**：B3 有 7 个 Stage、26 个块；核心块是“1×1 扩展 → Depthwise → SE → 1×1 线性投影”，满足维度条件才加残差。EfficientNet 的关键是高效块配合深度、宽度、分辨率的复合缩放。本实现把 `300×300` 图像变成 `1536×10×10` 的空间特征。
