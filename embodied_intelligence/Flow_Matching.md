# Flow Matching：学习从噪声到动作的速度场

> 前置：[DDPM](DDPM.md)、[DDIM](DDIM.md)、[EDM](EDM.md)。以具身智能的未来动作块为例，重点是训练目标、张量形状、ODE 采样和方法对比；不展开论文推导，不放伪代码。
>
> 主线采用最容易复习的**直线插值 Conditional Flow Matching（CFM）**：先造噪声到示范动作之间的点，再让网络学习该往哪里走。FM 本身允许更一般的概率路径，并不只限于直线。

## 1. 先说扩散模型的优缺点，FM 改进什么

扩散策略把未来动作块作为生成对象，图像、状态、目标或指令作为条件。它比直接输出一条确定性动作，更适合表达“左绕、右绕都合理”的多峰行为。

| 扩散模型的优势 | 对应的代价 / 注意点 |
|---|---|
| 可表达多模态动作分布，一次生成有时间关联的动作块 | 通常需要多次网络调用，增加规划延迟 |
| 随机选噪声等级训练，噪声目标可以直接构造 | 要处理噪声表、输出参数化、损失权重等相互配合的设计 |
| 有 DDIM、EDM 等成熟的少步采样方法 | 采样步数太少仍可能损害动作质量，且要按网络调用次数比较成本 |

**FM 的核心变化是直接学习概率路径上的速度场**。选定一条容易构造的路径后，训练样本和速度监督都有简单表达；推理再用 ODE 求解器把初始噪声搬到动作分布。

直线路径提供了减少弯曲和少步积分的设计机会，适合关注时延的具身策略。但 FM **不自动消除迭代，不保证比调好的扩散策略更快或更准，也不天然解决碰撞与动力学约束**。

特别注意：DDIM、EDM 已经能使用确定性 ODE 思路。因此，“可以用 ODE、无需每步加随机噪声”不是 FM 独有的优势；FM 的重点是**路径与速度监督的直接构造方式**。

## 2. 符号、时间方向与形状

| 符号 | 含义 | 示例 |
|---|---|---|
| `A` | 真实、归一化后的干净动作块 | `[B,Ha,Da]=[2,16,7]` |
| `z` | 高斯噪声，与动作同形状 | `[2,16,7]` |
| `x_t` | 生成时间 t 对应的中间动作状态 | `[2,16,7]` |
| `t` | 连续生成时间 | `[0,1]`，训练时每个样本可独立采样 |
| `u_t` | 构造路径提供的目标速度 | `[2,16,7]` |
| `v_theta(x_t,t,c)` | 网络预测的速度 | `[2,16,7]` |
| `c` | 图像、状态、目标 / 指令编码出的条件 | 如 `[B,256]`，也可保留为条件 token |
| `S` | 推理的积分区间数 | 如 10，仅为示例 |

本篇统一采用：

```text
t=0：噪声 z  ── 时间逐渐增大 ──>  t=1：动作 A
```

前面 DDPM 笔记用 `x_0` 表示干净动作；**本篇的生成时间从噪声端开始**，所以改用 `A` 表示干净动作，避免把两种下标约定混在一起。

`Ha=16` 是真实未来动作序列的长度，`t` 是生成这整段序列的过程。**生成时间、机器人控制时间、观测历史时间是不同的轴。**

## 3. 训练路径：在噪声和示范动作之间插值

### 最常见的直线路径

$$
\boxed{x_t=(1-t)z+tA,\qquad z\sim\mathcal N(0,I).}
$$

直觉：t 越小越接近噪声，越大越接近示范动作；训练时已知两端，可以直接算出任意中间点。

这与扩散的“从干净数据向噪声加噪”在叙述方向上相反，但训练都能直接构造中间状态，不必逐步模拟。FM 的路径也可以反过来参数化，只要训练目标和推理方向一致。

对这个插值求时间导数：

$$
\boxed{u_t=\frac{d x_t}{dt}=A-z.}
$$

直觉：对某一对固定的噪声与示范，沿直线从起点走到终点所需的速度就是“终点减起点”。它描述**动作张量在生成过程中的变化率**，不是机械臂的真实线速度或关节速度。

同一对端点的 `A-z` 不随 t 变化，但不同端点对的方向不同；不能据此认为网络在所有位置、所有时间都应输出同一个速度。

### 更一般的路径，只需再记一行

$$
x_t=a(t)A+b(t)z,\qquad u_t=a'(t)A+b'(t)z.
$$

直觉：路径怎么混合数据和噪声，速度就是混合系数随时间变化的导数。直线对应 `a(t)=t、b(t)=1-t`；FM 也能选择扩散式或其他路径。

## 4. 训练：回归速度，不用先求解 ODE

训练数据是观测与示范动作对 `(o,A)`。基础做法独立采样 `z`，并令 `t` 在 `[0,1]` 上均匀采样；时间分布也可以根据任务调整。

$$
\boxed{\mathcal L_{\mathrm{CFM}}=
\mathbb E\left[\|v_\theta(x_t,t,c)-(A-z)\|_2^2\right],
\qquad c=\operatorname{Encoder}(o).}
$$

直觉：把中间状态、生成时间和观测交给网络，让它预测这对端点提供的目标方向。这里的 MSE 是速度回归，不是只根据观测回归平均动作。

```text
观测图像 / 状态 / 指令 ── Encoder ──> c [B,256] ───────┐
                                                      │
示范动作 A                  [B,16,7]                   │
独立高斯噪声 z              [B,16,7]                   │
随机时间 t                  [B] → 广播为 [B,1,1]       │
          │                                           │
          ├─ 插值：x_t=(1-t)z+tA   [B,16,7] ───────────┤
          └─ 标签：u_t=A-z        [B,16,7]             │
                                                      ▼
                                       速度网络 v_theta(x_t,t,c)
                                                      │ [B,16,7]
                                                      ▼
                                         与目标 u_t 比较，计算 MSE
```

同一动作块的全部未来位置通常共享一个 t，噪声元素独立采样。若存在填充动作或无效维度，训练损失要相应屏蔽；不同动作维度也应先归一化。

**一次训练通常只为每个样本抽一个 t、调用一次速度网络，不需要沿整条生成路径积分。** 这常称为 simulation-free training；并不表示推理不需要积分，也不是扩散训练做不到的能力。

### 为什么端点给出的速度，能训练生成时用的速度场？

生成时只知道当前 `x_t`，不知道它应该属于哪个示范端点。平方损失学到的是当前状态与条件下，端点速度的条件平均：

$$
v^*(x,t,c)=\mathbb E[A-z\mid x_t=x,t,c].
$$

直觉：训练时用容易计算的“每对端点的方向”作标签，聚合后得到能推动中间**概率分布**变化的速度场；不需要事先知道每个采样最终会对应哪个示范。

这不是从观测直接计算 `E[A|c]`。速度还依赖当前生成状态和时间，不同初始噪声可以沿不同路径到达不同动作模式。**模型有表达多峰的能力，但不保证每个模式都被学好。**

## 5. 1D U-Net / 动作 DiT 如何接进去？

把原来的噪声预测网络改成速度预测网络，张量接口可以相同，但监督含义改变：

```text
输入 x_t [B,16,7] + 时间 t + 条件 c
                    │
        ┌───────────┴───────────┐
        ▼                       ▼
条件 1D U-Net                动作 DiT
转为 [B,7,16]              Linear(7 → D)
沿动作长度卷积              [B,16,D] + 位置编码
下采样 / 上采样 + skip      Transformer blocks
转回 [B,16,7]              Linear(D → 7)
        │                       │
        └───────────┬───────────┘
                    ▼
             v_theta [B,16,7]
```

时间 t 经 embedding 后，与全局条件一起注入各层：U-Net 可用 FiLM 的缩放 / 偏置，DiT 可用 adaLN。保留视觉、语言 token 时，也可以通过 Cross-Attention 读取条件。

本次动作采样中，观测条件通常固定并复用，变化的是 `x_t` 和 t；下一次闭环规划再读取新观测。动作位置编码用于区分未来第几步，和生成时间 embedding 不同。

**架构兼容不等于权重可以不加处理地复用。** 不能把 DDPM 的 epsilon 输出直接当作 FM 速度；一般需要按 FM 目标训练，或进行与原概率路径、尺度和时间参数一致的严格转换。

## 6. 推理：从噪声沿速度场积分到动作

$$
\boxed{\frac{d x_t}{dt}=v_\theta(x_t,t,c),\qquad x_{t=0}=z.}
$$

直觉：网络告诉当前状态应该往哪里、以多大变化率移动，求解器累计这些局部更新，到 `t=1` 得到生成动作块。

```text
当前观测 → 条件 c
高斯噪声 z [B,16,7]
       │ 选择时间网格：0=t_0 < t_1 < ... < t_S=1
       ▼
在当前 x_t、t、c 上预测速度 [B,16,7]
       │ ODE 求解器更新 x，并增加 t
       ▼
重复 S 个区间 → 生成动作块 [B,16,7]
       │ 反归一化，按任务恢复动作表示
       ▼
执行对齐的一小段 → 获取新观测 → 重新规划
```

### Euler：用起点速度走一步

$$
\boxed{x_{\mathrm{next}}=x_t+h\,v_\theta(x_t,t,c),
\qquad h=t_{\mathrm{next}}-t>0.}
$$

直觉：使用起点切线外推。一阶方法，每个区间通常一次网络调用；本篇 t 从 0 增至 1，所以步长为正，与 EDM 的递减 sigma 不同。

### Heun：预测终点，再平均速度

$$
v_0=v_\theta(x_t,t,c),\qquad x_{\mathrm{temp}}=x_t+h v_0,
\qquad v_1=v_\theta(x_{\mathrm{temp}},t+h,c).
$$

直觉：先用 Euler 预测临时终点，再在那里重新评估速度；临时终点不是真实已知终点。

$$
\boxed{x_{\mathrm{next}}=x_t+\frac h2(v_0+v_1).}
$$

直觉：平均两端预测速度，更好地近似区间内方向变化。Heun 是二阶方法，通常每区间两次调用；不保证在所有步长、网络误差下都优于 Euler。

FM 的速度公式不含 EDM 的 `1/sigma` 除法，不能照搬“最后一定要 Euler 收尾”的规则；是否可评估端点，取决于具体模型和时间 embedding。FM 也能使用其他兼容 ODE 求解器。

### 一个标量例子

假设观测条件固定，在 `t=0.4、x=0.5` 时网络预测 `v0=2`，下一时间点为 `0.6`，所以 `h=0.2`：

| 计算 | 数值 | 含义 |
|---|---|---|
| Euler / 临时终点 | `0.5 + 0.2×2 = 0.9` | Euler 到此结束 |
| 在临时终点重新评估 | 假设 `v1=1.5` | 需要再次调用网络，并非事先知道 |
| Heun 修正 | `0.5 + 0.2×(2+1.5)/2 = 0.85` | 从原状态 0.5 出发，用平均速度更新 |

没有真实解时，不能仅凭两个结果不同就断言 Heun 这次一定更准。比较推理效率要看 NFE（网络调用次数）、控制延迟与任务成功率，不能只看步数。

## 7. 三个重点：直线路径、少步采样与多模态

### 训练插值是直线，为什么推理轨迹可能弯？

每对 `(z,A)` 的训练插值都是直线，但不同端点对的方向会混合，网络学的是前述条件平均速度。推理跟随**学到的整体速度场**，并不知道预先指定的终点，因此积分轨迹不保证是某条训练直线。

这也是“直线监督 → 一步精确生成”不成立的原因。只有速度场沿该采样路径足够稳定、模型又足够准确时，大步 Euler 才容易取得好效果。

### FM 为什么有机会少步生成？

路径与端点配对设计得合适时，学到的轨迹可以较平直，有限步积分的误差较小；直接回归速度也让训练和采样接口清晰。但**配对方式、路径曲率、网络误差和求解器共同决定实际步数**。

更少步数也可能需要 reflow 或蒸馏等额外训练。FM 本身不等于一步生成器。

### 确定性 ODE 为什么仍能生成多模态动作？

```text
同一个观测条件 c
    ├─ 初始噪声 z1 → 一条积分轨迹 → 左绕动作块
    └─ 初始噪声 z2 → 另一条积分轨迹 → 右绕动作块
```

随机性来自初始噪声；给定初始噪声、条件和求解设置后，基础 ODE 路径是确定的。不需要每一步重新加噪才能多模态，原理上和 DDIM 的 eta=0 情况相通。

不要把多个模式的最终动作直接逐点平均，否则仍可能回到“左右都对，平均走中间”的问题。

## 8. FM、CFM、Rectified Flow 与 OT：分清概念

| 概念 | 需要记住的区别 |
|---|---|
| Flow Matching | 通过回归速度场来训练连续流模型的总体框架，可选不同概率路径 |
| Conditional Flow Matching | 用已知端点等辅助条件构造可计算路径与速度标签，间接学习整体速度场 |
| 观测条件 c | 图像、状态、指令等任务信息；与 CFM 中用于构造路径的辅助条件不是同一概念 |
| Rectified Flow | 与直线插值速度回归密切相关的一类方法；基础训练可以与本文形式重合，还强调通过 reflow 等方式改善路径直线性 |
| reflow | 用已有流模型生成噪声—终点配对，再训练新的流模型；这是额外训练步骤，不是简单减少推理循环 |
| OT 配对 | 调整噪声与数据的 coupling，让配对整体运输代价更小，可能改善轨迹几何；不同于一开始独立随机配对 |

**基础 FM 不必求解最优传输。** “每对端点之间用直线”也不代表整个噪声—数据配对已经是全局 OT 最优；某些代码中的 `CondOT` 名称不能直接这样解读。

## 9. 与 DDPM / DDIM / EDM 的对比

下表按前面笔记的常见版本比较；FM 列采用本文直线 CFM，不能外推为所有 FM 的唯一公式。

| 对比项 | DDPM | DDIM | EDM | 直线 FM / CFM |
|---|---|---|---|---|
| 训练中间状态 | `sqrt(alpha_bar_t)A + sqrt(1-alpha_bar_t)epsilon`：信号衰减加噪 | 通常复用 DDPM 的训练边缘分布 | `A+sigma*epsilon`：加性噪声 | `(1-t)z+tA`：噪声与动作插值 |
| 网络常见目标 | epsilon，也有 x0 / v 参数化 | 复用原模型目标 | 完整 D 输出干净动作，内部 F 输出预条件残差 | 路径速度 `A-z` |
| 生成时间方向 | 大噪声等级 → 小等级 | 选定高噪声等级 → 低等级 | sigma 从大到小 | 本文 t 从 0 到 1；可反向约定 |
| 推理更新 | 离散反向均值 + 方差采样 | 跨时间点更新，eta 控制随机性 | 干净估计转成 ODE 斜率，再积分；也有随机变体 | 直接预测 ODE 速度，再积分 |
| 少步方式 | 需匹配重间隔采样规则 | 可选稀疏时间点 | 选择 sigma 网格与积分器 | 选择 t 网格与积分器，路径设计也影响难度 |
| 去噪 / 速度网络 | U-Net、Transformer 等 | 通常复用同一网络 | U-Net、Transformer 等 + 对应预条件 | U-Net、动作 DiT 等 |

### 和 EDM 最容易混淆的差别

EDM 先预测干净动作，再由采样器计算方向：

$$
d(y,\sigma)=\frac{y-D_\theta(y;\sigma)}{\sigma}.
$$

直觉：EDM 的方向由当前状态和干净估计共同构造；本文 FM 网络直接回归与所选插值路径对应的速度。两者都是连续向量场生成，区别不只是“有没有 ODE”。

本文直线 FM 还可以从速度构造一个干净端点估计：

$$
\hat A=x_t+(1-t)v_\theta(x_t,t,c).
$$

直觉：用当前局部速度外推剩余生成时间，可得到一个端点估计；它不是精确终点，也不能据此把后续积分都省掉。该关系与本篇路径和速度目标绑定，不适用于任意 FM 路径。

另外，扩散里的 **v-prediction** 有其特定的信号 / 噪声混合定义，不能因为都叫 v，就当成这里的 `A-z`。切换目标时，路径、时间方向、输出变换和采样器都必须一致。

## 10. 具身智能复习时额外关注什么？

| 关注点 | 为什么重要 |
|---|---|
| 时间方向与符号 | 有实现定义 t=0 为动作、t=1 为噪声，此时标签变成 `z-A`，推理从 1 积分到 0；单看减号不能判断代码有错 |
| 动作归一化 | 平移、旋转、关节和夹爪尺度可能不同，不处理会改变插值与速度损失的相对权重 |
| 旋转表示 | 本篇按欧氏动作向量插值；对旋转矩阵、四元数等不能忽略合法性和几何结构，需合适参数化或流形方法 |
| 动作块时间对齐 | 预测长度、执行片段和历史观测对应关系必须与训练一致 |
| 真实控制性能 | 更少 NFE 不必然意味着更高成功率，还要看推理耗时、闭环频率与动作稳定性 |

基础 FM 不需要 Langevin corrector，也不要求 eta 这类逐步噪声强度参数。若采用随机变体、引导或额外纠正步骤，应按具体方法另外说明。

## 11. 面试八股

| 问题 | 精炼回答 |
|---|---|
| 1. Flow Matching 的核心是什么？ | 构造从简单噪声分布到数据分布的概率路径，回归对应速度场，推理通过 ODE 积分生成样本。 |
| 2. 本文训练路径和目标是什么？ | `x_t=(1-t)z+tA`，目标速度 `u_t=A-z`；按时间从噪声端走向动作端。 |
| 3. 为什么训练不需要求解 ODE？ | 已知示范与噪声端点，可以直接采样中间点和速度标签，不用先模拟完整路径。 |
| 4. 速度是机器人实际运动速度吗？ | 不是；它是整段动作张量相对生成时间的变化率，和真实控制时间不同。 |
| 5. 用 MSE 会不会又只生成平均动作？ | 速度还依赖中间状态和时间，不是仅根据观测回归动作均值；不同初始噪声可到不同模式。 |
| 6. FM 和 EDM 都用 ODE，差在哪？ | EDM 常先估计干净动作再换算方向；本文 FM 直接监督所选路径上的速度，训练路径与参数化不同。 |
| 7. 训练走直线，推理也一定走直线吗？ | 不一定；单对端点是直线，网络学的是条件平均速度场，积分路径仍可能弯曲。 |
| 8. FM 是不是一步生成？ | 不是；基础方法仍需积分。少步质量取决于路径、配对、模型和求解器，一步常需进一步优化或蒸馏。 |
| 9. 确定性 ODE 怎么表达左右两种动作？ | 初始噪声不同，积分轨迹和最终动作可以不同；确定性是固定初始条件后的性质。 |
| 10. FM 与 Rectified Flow 是什么关系？ | 基础直线速度回归形式可重合，但 FM 是更一般的框架；Rectified Flow 还强调重配对 / reflow 改善轨迹。 |
| 11. FM 必须做最优传输吗？ | 不必；独立配对就能训练。OT 配对可改善运输几何，但直线插值不等于全局 OT。 |
| 12. 比扩散模型好在哪里，有什么限制？ | 速度监督直接、路径选择灵活，合适设计下有利于少步采样；但扩散也能少步和 ODE 采样，FM 没有无条件的速度或质量优势。 |

## 12. 一句话总结 Flow Matching

**FM 用噪声与示范动作构造中间状态，训练网络预测生成速度，再沿条件速度场多步积分，把一段随机噪声变成完整动作块。**
