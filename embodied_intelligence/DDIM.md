# DDIM：复用 DDPM 去噪网络，用更少步骤生成动作

> 重点：不重新训练如何切换采样，前向关系为什么能复用，反向如何跳步，以及 eta（η）到底控制什么。
>
> 前置：[DDPM](DDPM.md)。全文用未来动作块举例，公式保持面试所需的范围。

## 1. DDIM 和 DDPM 是什么关系？

工程上可以把 DDIM 理解为 **与 DDPM 训练兼容的采样改进**：保留已经训练好的去噪网络，在推理阶段更换采样更新方式，支持确定性采样与少步采样。

```text
训练：示范动作 + 加噪 + 观测条件 → 训练 epsilon_theta
                                     │
                         同一份去噪网络权重
                                     │
                     ┌───────────────┴───────────────┐
                     ▼                               ▼
               DDPM 采样器                     DDIM 采样器
             通常逐相邻步采样               可用较稀疏的时间点去噪
                     │                               │
                     ▼                               ▼
                 动作块                          动作块
```

“不需要重新训练”有前提：沿用训练对应的噪声表 / 累计系数、噪声等级含义、输入输出归一化，以及网络的 `prediction_type`。不要随手换成另一张完全不同的 beta 表。

DDIM 换的是采样路径，不是把模型改成另一个网络。1D U-Net 或动作 DiT 都可以继续作为同一个 `epsilon_theta(x_t,t,c)`。

## 2. 前向过程：保留相同的加噪边缘分布

和 DDPM 一样，训练时仍可一步构造：

$$
\boxed{x_t=\sqrt{\bar\alpha_t}x_0+
\sqrt{1-\bar\alpha_t}\epsilon,\qquad\epsilon\sim\mathcal N(0,I).}
$$

```text
真实动作 x_0               [B,Ha,Da] = [2,16,7]
噪声 epsilon               [2,16,7]
噪声等级 t                 [2]
         │ 和 DDPM 相同的边缘加噪关系
         ▼
带噪动作 x_t               [2,16,7]
         │ 同一去噪网络 + 观测条件 c
         ▼
epsilon_hat                [2,16,7]
```

严格地说，DDIM 从一族可以非马尔可夫的前向联合过程出发，**保留 `q(x_t | x_0)`，不要求保留 DDPM 原来的每个相邻步转移**。所以既能复用训练目标，又能有不同的生成路径。

面试讲到这里即可，不必推导整条非马尔可夫联合分布。也不要理解成训练时真的把去噪链跑短了才得到 DDIM。

## 3. 参数表：哪些继承，哪些是推理时改？

| 参数 / 符号 | 含义 | 实际关注点 |
|---|---|---|
| `N / num_train_timesteps` | 训练噪声表的等级数 | 如 1000，沿用训练配置 |
| `S / num_inference_steps` | 推理调用去噪网络的步数 | 如 20、50，需要在任务上验证 |
| `t` | 当前噪声等级 | 是原训练时间表上的索引 |
| `s` | 下一次要到达的较低噪声等级 | `s<t`，不一定为 `t-1` |
| `alpha_bar_t, alpha_bar_s` | 对应两个等级的累计保留系数 | 从原噪声表中取，不能重建一张 S 步表替代 |
| `eta / η` | 反向更新中新加随机噪声的强度系数 | 常用 0；常见讨论范围为 `[0,1]` |
| `sigma_(t→s)` | 这次跳步添加的噪声标准差 | 由 η 与 t、s 两端系数共同决定 |
| `timestep_spacing` | S 个推理时间点怎么选 | 如等间隔、不同端点对齐策略 |
| `prediction_type` | 网络预测 epsilon、x0 还是 v | 必须匹配训练 |
| `seed / generator` | 初始噪声与随机采样控制 | η=0 时初始噪声也能改变输出 |
| `clip_sample` 等 | 是否截断预测的干净动作 | 与动作归一化和参考实现对齐 |

`S=20` 指每次生成动作调用约 20 次去噪网络，不是输出 20 个动作；输出长度由 `Ha` 决定。常见离散 DDIM 选择 `S≤N`。

η 是这里的采样参数，推理时可以调整，不是需要训练的网络权重。

## 4. 反向第一步：根据噪声预测估计干净动作

当前有 `x_t`，网络预测噪声：

```text
eps_hat = epsilon_theta(x_t, t, c)       [B,16,7]
```

用前向公式反解得到干净动作估计：

$$
\boxed{\hat x_0=
\frac{x_t-\sqrt{1-\bar\alpha_t}\,\hat\epsilon}
{\sqrt{\bar\alpha_t}}.}
$$

`x_hat_0` 是**当前噪声等级下估计的完整动作块**，不是已经有了保证准确的动作，也不是只预测一个动作位置。

下一次网络调用会基于更新后的动作重新估计噪声与 `x_hat_0`，不是把第一次的估计固定到底。

## 5. 反向第二步：直接从 t 更新到任意 s<t

DDIM 广义采样式可以只记这一个：

$$
\boxed{
x_s=
\underbrace{\sqrt{\bar\alpha_s}\hat x_0}_{\text{估计的干净动作成分}}
+\underbrace{\sqrt{1-\bar\alpha_s-\sigma_{t\to s}^2}\,\hat\epsilon}_{\text{保留的噪声方向}}
+\underbrace{\sigma_{t\to s}z}_{\text{新加入的随机性}},
\quad z\sim\mathcal N(0,I).
}
$$

其中：

$$
\boxed{
\sigma_{t\to s}=
\eta\sqrt{\frac{1-\bar\alpha_s}{1-\bar\alpha_t}}
\sqrt{1-\frac{\bar\alpha_t}{\bar\alpha_s}}.
}
$$

面试按三个部分解释即可：**估计干净动作 + 到下一噪声等级所需的方向项 + 可调随机噪声**。

前两项的系数也会随 η 改变，不能只在一个固定的确定性更新末尾随意加 `eta * randn`。

```text
输入：x_t [B,16,7]、t、s、c [B,256]
             │
             ▼ 去噪网络，使用当前原始噪声等级 t
eps_hat      [B,16,7]
             │ 根据 alpha_bar_t 反解
             ▼
x_hat_0      [B,16,7]
             │ 使用 alpha_bar_s、sigma_(t→s) 做更新
             ▼
x_s          [B,16,7]
```

## 6. η=0、η>0、η=1 分别意味着什么？

### η=0：确定性去噪，常用于少步动作推理

此时 `sigma_(t→s)=0`，没有每一步新加的随机噪声：

$$
x_s=\sqrt{\bar\alpha_s}\hat x_0+
\sqrt{1-\bar\alpha_s}\hat\epsilon.
$$

```text
给定同一个初始动作噪声、同一个条件、同一个时间表
                  │
                  ▼ η=0
           后续采样路径由它们确定
```

机器人推理常把 η 设为 0，便于控制重复性、调试和延迟。**推理速度主要来自减少 S，不是 η=0 自动减少网络调用次数。** 它也不自动保证机器人动作更安全或平滑。

η=0 仍然可以生成多条轨迹：给相同观测采样不同的初始 `x_N` 即可。想复现同一次输出，需要同时固定初始噪声、条件、时间表，并关闭网络中的训练态随机性。

η=0 也不表示中间动作已经没有噪声：只要还没到干净端点，更新式仍有保留噪声方向的第二项。**DDIM 的确定性更新不等于直接删除 DDPM 公式末尾的随机项**，其余更新系数也不同。

### 0<η<1：每次去噪加入一定随机性

同一个初始动作噪声，也可以因为后续注入的 `z` 不同而得到不同结果。它可以增加采样路径的随机性，但不是“探索能力”或“轨迹质量”的直接旋钮；效果需要结合任务验证。

即使 η=0，改变初始噪声也已有多样性，因此不是必须把 η 调大才有多模式动作。

### η=1：什么时候能说退化成 DDPM？

如果使用**完整的相邻时间步** `s=t-1`，则：

$$
\sigma_{t\to t-1}^2=
\frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}
\left(1-\frac{\bar\alpha_t}{\bar\alpha_{t-1}}\right)
=\tilde\beta_t.
$$

在网络参数化、截断处理和边界处理也一致时，它与 **使用后验方差 `tilde_beta_t` 的 DDPM 采样更新**等价。

所以面试可以先说“η=1 可以恢复 DDPM”，再补充条件：

- **完整相邻步 + fixed-small 后验方差**时，对应标准的这一种 DDPM 更新。
- 如果只保留稀疏时间点，η=1 对应这个**缩短时间链上的随机祖先式采样**，不等于重新执行了原 N 步 DDPM。
- 如果某个 DDPM 实现使用 `beta_t` 方差、学习方差或不同截断规则，不能无条件说两者数值完全相同。

## 7. 跳步：你的“换下标”直觉该怎么落地？

可以按“**选一组原始时间点，把相邻更新推广成 t→s**”来记。

例如训练有 `N=1000` 个噪声等级，推理选一组递减时间点，示意为：

```text
训练数学等级：1, 2, ..., 1000

完整相邻采样：1000 → 999 → 998 → ... → 1 → 干净动作
稀疏时间采样：1000 → 950 → 900 → ... → 50 → 干净动作
```

实际采样点由 scheduler 的时间表决定，上面只是方便理解的例子。

假设这次是 `t=900 → s=850`：

```text
1. 网络输入当前动作 x_900 和原始噪声等级 900。
2. 取训练噪声表里的 alpha_bar_900，估计 x_hat_0。
3. 取 alpha_bar_850，并结合两个端点计算 sigma_(900→850)。
4. 用 DDIM 更新式直接得到 x_850。
5. 下一次网络输入 x_850 和噪声等级 850。
```

**不需要依次调用网络计算 x_899、x_898……x_851，所以能省网络调用。**

### 不能只改 for 循环下标，其他量保持不变

“把下标换成对应步数”适用于上面的广义 DDIM 更新式，但所有有关的累计系数、噪声方差、方向系数都要一起匹配端点。

如果从 DDPM 相邻步的角度理解跳步，跨越 `s→t` 的有效单步保留系数应是 `alpha_bar_t / alpha_bar_s`，有效方差是 `1 - alpha_bar_t / alpha_bar_s`，不能仍使用原相邻步的 `beta_t`。

也不要把选出的 20 个时间点重新编号成 `0...19` 后直接喂给网络。循环序号和模型见过的噪声等级是两回事。

## 8. 最后到干净动作的边界怎么处理？

数学记号里干净状态的 `alpha_bar_0=1`。当 `s=0`：

```text
sigma_(t→0) = 0
方向项系数 = 0
x_0 = x_hat_0
```

代码里通常用 `0...N-1` 标记噪声等级，因此最后的“干净端点”可能用 `prev_t=-1` 等哨兵表示，并规定该端点累计系数为 1。不要直接访问数组 `[-1]` 把它当成干净系数，否则可能取成最高噪声端。

不同库对最后一步、起始点、时间间隔的约定有差异。使用具体 scheduler 时，应遵循它的 `set_timesteps` 和 `step` 实现，不混用数学下标与数组下标。

## 9. 放进具身策略的完整推理流程

```text
相机历史、状态、任务目标
          │ 观测编码器，本次规划计算一次
          ▼
c [B,256] ──────────────────────────────┐
                                       │
初始动作噪声 [B,16,7]                   │
          │ 按 S 个时间点循环           │
          ▼                            │
U-Net / 动作 DiT(x_t,t,c) ◀─────────────┘
          │
          ▼ eps_hat [B,16,7]
DDIM scheduler.step(..., eta=0)
          │
          ▼ x_s [B,16,7]
        循环结束
          │
          ▼
生成动作块 → 反归一化 → 执行对齐的一小段 → 新观测 → 再规划
```

1D U-Net 仍可用全局条件与时间 embedding 拼接，通过残差块的缩放 / 偏置注入；DiT 仍可用 adaLN 或 Cross-Attention。**切换 DDIM 不改变它们的条件注入结构**，逐层形状见 [DDPM](DDPM.md)。

```python
# 伪代码，接口以 diffusers 风格说明；不是一份独立可运行脚本。
# ddim_scheduler 使用与训练相容的噪声表与 prediction_type。
denoiser.eval()
encoder.eval()
ddim_scheduler.set_timesteps(num_inference_steps=S)

with torch.no_grad():
    c = encoder(observations)                     # [B,Dc]
    x = torch.randn(B, Ha, Da, device=device)      # [B,Ha,Da]
    for t in ddim_scheduler.timesteps:
        eps_hat = denoiser(x, timestep=t, global_cond=c)
        x = ddim_scheduler.step(
            model_output=eps_hat,
            timestep=t,
            sample=x,
            eta=0.0,
        ).prev_sample
    actions = unnormalize(x)                     # [B,Ha,Da]
```

网络在循环里预测噪声，scheduler 负责重建 `x_hat_0` 和计算下一步；`.prev_sample` 指时间表里的下一个低噪声样本，不一定是原始训练下标的 `t-1`。

## 10. 面试八股：重点防这几处

| 问题 | 建议回答 |
|---|---|
| DDIM 要重新训练吗？ | 通常不用；可复用 DDPM 式训练好的噪声预测器，但噪声表、参数化和数据处理需匹配。 |
| DDIM 是不是把前向过程完全照搬 DDPM？ | 保留相同的加噪边缘分布，完整联合过程可以不同，因此采样路径可以不同。 |
| η=0 后模型还有随机性吗？ | 给定初始噪声和条件后路径确定；初始噪声本身仍可随机。 |
| η=1 一定完全等于某个 DDPM 库的输出吗？ | 不一定；相邻完整步、后验方差及其他实现约定一致时才对应。 |
| η 和 guidance scale 一样吗？ | 不一样；η 控制采样中新注入的随机噪声，guidance scale 调节条件引导强度。 |
| 为什么跳步还能用原来的模型？ | 模型学会了各噪声等级的预测；更新式用两个端点的累计系数重组到较低噪声等级。 |
| 跳得越多一定越好吗？ | 网络调用更少，但近似误差可能增大；需要权衡控制延迟和任务成功率。 |
| 只训练 20 级和 1000 级训练后 20 步采样一样吗？ | 不一样；训练噪声表与学习覆盖不同，不能只看推理步数。 |
| η=0 是不是只会出一条固定动作？ | 对固定初始噪声成立；换初始噪声仍可生成不同动作模式。 |
| 固定初始噪声，换 S 输出一样吗？ | 有限步数、网络误差下通常不同，不能认为确定性就对时间表无关。 |
| 动作很短，可以把扩散步数设成动作步数吗？ | 二者没有必须相等的关系，应分别按任务与时延选择。 |

## 11. 面试够用的复述

> DDIM 可以复用 DDPM 训练出的条件去噪网络，通常不需要重新训练。它先从当前带噪动作预测噪声并估计干净动作，再用当前和目标噪声等级的累计 alpha，直接更新到选定的低噪声时间点。η=0 时不再逐步注入随机噪声，但初始噪声仍可随机；η=1 在完整相邻步、后验方差一致时恢复相应的 DDPM 更新。速度主要来自减少采样步数，不能只是改循环跳步而不改更新系数。
