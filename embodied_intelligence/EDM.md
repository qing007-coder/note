# EDM：连续噪声尺度、预条件器与 ODE 动作采样

> 已学 [DDPM](DDPM.md)、[DDIM](DDIM.md) 后阅读。本篇将生成对象视为未来动作块，聚焦原理、公式直觉与面试要点，不展开论文推导或伪代码。

## 1. 整体思想：把扩散的设计拆开讲清楚

EDM（Elucidating the Design Space of Diffusion Models）系统梳理了扩散模型的**噪声参数化、网络预条件、训练权重、采样调度和数值积分器**，并给出一组有效的组合。

它直接用连续噪声标准差 `sigma` 描述“现在有多吵”，以加性高斯噪声构造训练数据；去噪器输出干净数据估计，采样器据此计算 ODE 方向，从高噪声逐步积分到低噪声。

相对常见 DDPM / DDIM 的离散时间表写法，EDM 把**噪声尺度与采样步数解耦**：训练在连续噪声尺度上学习，推理再选择有限的噪声节点和求解方法。DDPM、DDIM 也能联系连续时间理论，因此不要把“连续”当作 EDM 独有的概念。

**EDM 仍需要多步迭代；每次预测干净动作，不代表一次网络调用就完成生成。** 本篇先讲确定性 ODE 采样；EDM 也允许加入随机扰动的采样变体。

### 统一符号与动作形状

| 符号 | 含义 | 动作场景示例 |
|---|---|---|
| `x_0` | 真实、干净、已归一化的动作块 | `[B,Ha,Da]=[2,16,7]` |
| `y` | 当前带噪动作状态 | `[2,16,7]` |
| `sigma` | 当前噪声标准差 | 每个训练样本可独立采样，广播为 `[B,1,1]` |
| `epsilon` | 标准高斯噪声 | `[2,16,7]` |
| `x_hat` | 去噪器对干净动作的估计 | `[2,16,7]` |
| `c` | 图像、状态、目标或指令编码出的条件 | 如 `[B,256]` |
| `sigma_data` | 归一化后数据的典型标准差尺度 | 固定超参数，需与动作尺度匹配 |

为保持公式简洁，下文省略条件 `c`；具身策略实际使用 `D_theta(y; sigma, c)`。**动作块里的 16 个未来位置，与采样迭代次数是两回事。**

## 2. 训练：随机噪声尺度下重建干净动作

### 前向加噪

$$
\boxed{y=x_0+\sigma\epsilon,\qquad\epsilon\sim\mathcal N(0,I).}
$$

直觉：保留原动作幅度不变，额外叠加标准差为 `sigma` 的噪声；`sigma` 越大，动作结构越难辨认。

这里不像 DDPM 常见公式那样同时缩放干净信号。训练时可以直接构造任意尺度的 `y`，不必逐步加噪。

### sigma 怎么采样？

$$
\ln\sigma\sim\mathcal N(P_{\mathrm{mean}},P_{\mathrm{std}}^2),
\qquad\sigma=\exp(P_{\mathrm{mean}}+P_{\mathrm{std}}z),
\quad z\sim\mathcal N(0,1).
$$

直觉：先在对数空间采样一个正态数，再指数化，得到始终为正、能覆盖多个数量级的噪声尺度，这就是 log-normal（对数正态）分布。

`P_mean` 控制对数尺度的中心，`P_std` 控制覆盖宽度。原实现常用 `-1.2、1.2`，这是参考配置，不是机器人动作任务的固定最优值；也不是在 sigma 轴上均匀采样。

### 网络输入、输出与损失

```text
示范动作 x_0 [B,16,7] + sigma * epsilon
                       │
                       ▼
带噪动作 y [B,16,7] + sigma + 观测条件 c
                       │ 预条件去噪器 D_theta
                       ▼
干净动作估计 x_hat [B,16,7]
                       │ 与真实 x_0 比较
                       ▼
按噪声尺度加权的重建损失
```

$$
\mathcal L=\mathbb E\left[\lambda(\sigma)
\|D_\theta(x_0+\sigma\epsilon;\sigma)-x_0\|_2^2\right].
$$

直觉：无论动作被污染到哪个噪声等级，都训练模型恢复干净动作；不是监督它直接输出下一噪声等级的状态。

EDM 配套的常见权重为：

$$
\lambda(\sigma)=\frac{\sigma^2+\sigma_{\mathrm{data}}^2}
{(\sigma\sigma_{\mathrm{data}})^2}
=\frac{1}{c_{\mathrm{out}}^2}.
$$

直觉：不同噪声等级的重建难度和输出尺度不同，权重与预条件器配合，平衡它们对训练的贡献；不是保证每个等级最终贡献完全相同。

**训练时的 log-normal 分布决定“哪些噪声等级经常被训练”；推理时的 Karras 调度决定“在哪些噪声等级调用网络”。** 二者作用不同。

## 3. 预条件器：让网络在各种噪声下都好学

### 完整公式

$$
\boxed{D_\theta(y;\sigma)=c_{\mathrm{skip}}y+
c_{\mathrm{out}}F_\theta(c_{\mathrm{in}}y,c_{\mathrm{noise}}).}
$$

直觉：先缩放带噪输入，让内部网络预测一个尺度合适的残差，再与输入的直接通路相加，得到干净动作估计。

**完整去噪器 `D_theta` 的输出是 `x_hat`；内部网络 `F_theta` 的裸输出是预条件后的残差，不应直接叫作 `x_0` 或 `epsilon`。**

| 系数 | 公式 | 人话解释 |
|---|---|---|
| 输入缩放 | `c_in = 1 / sqrt(sigma² + sigma_data²)` | 控制进入 F 的幅度，避免高噪声时输入数值过大 |
| 跳接比例 | `c_skip = sigma_data² / (sigma² + sigma_data²)` | 决定输入 y 有多少直接进入干净估计 |
| 残差缩放 | `c_out = sigma * sigma_data / sqrt(sigma² + sigma_data²)` | 把 F 的残差还原到合适的数据尺度 |
| 噪声编码 | `c_noise = (1/4) * ln(sigma)` | 将噪声等级压到对数尺度，再交给网络的噪声 embedding |

### 为什么需要它？

噪声跨度可能很大。如果所有尺度直接共用同一个裸网络，输入幅度、需要修正的量和梯度尺度都会随 sigma 大幅变化。

预条件器用确定的缩放，把内部网络的输入和目标维持在较稳定的量级：**低噪声时少改，高噪声时主要靠网络重建。** `sigma_data` 描述数据本身的典型尺度，不是当前观测的可信度；动作各维应先合理归一化，再确定这个尺度。

### 大噪声、小噪声时会怎样？

| 噪声范围 | `c_skip` | `c_out` | 直觉 |
|---|---|---|---|
| `sigma >> sigma_data` | 趋近 0 | 趋近 `sigma_data` | 原输入噪声很重，直接通路减弱，主要由 F 输出重建成分 |
| `sigma << sigma_data` | 趋近 1 | 近似 sigma，趋近 0 | 输入已经接近干净动作，只需小幅残差修正 |

高噪声时 `c_in` 近似 `1/sigma`，低噪声时近似 `1/sigma_data`，两端都在控制内部输入幅度。

它**有点像门控**，因为两个通路的比例随噪声变化，但这些系数由 sigma 和 sigma_data 解析计算，**不是网络学习出来的置信度，也不是两个概率权重**；`c_skip + c_out` 不要求等于 1。

### 接到具身智能的 U-Net / DiT 中

```text
y [B,16,7] ── c_in 缩放 ──> F_theta ── c_out 缩放 ──┐
                              ▲                      │
c_noise ── 噪声 embedding ─────┤                      ├─ 相加 → x_hat [B,16,7]
观测全局条件 c [B,256] ────────┘                      │
y [B,16,7] ─────────────── c_skip 直接通路 ───────────┘
```

`F_theta` 可以是沿动作序列卷积的 1D U-Net，也可以是动作 token 上的 DiT。观测条件仍可通过 FiLM、adaLN 或 Cross-Attention 注入；预条件器包在网络外侧，不改变动作块的最终形状。

## 4. 采样：沿概率流 ODE 从高噪声走向低噪声

### 初始化与方向

$$
y_{\mathrm{init}}=\sigma_{\max}z,
\qquad z\sim\mathcal N(0,I).
$$

直觉：从标准差为 sigma_max 的高斯动作噪声开始；sigma_max 应足够大，使数据成分相对噪声可以近似忽略。

在每个正噪声等级，先计算干净估计，再构造 ODE 斜率：

$$
\hat x=D_\theta(y;\sigma),\qquad
\boxed{\frac{dy}{d\sigma}=d(y,\sigma)
=\frac{y-D_\theta(y;\sigma)}{\sigma}.}
$$

直觉：比较当前动作与估计的干净动作，并按噪声尺度归一化，得到状态随 sigma 变化的方向。**网络预测的是 x_hat，斜率是采样器算出来的。**

```text
高斯动作噪声 y
      │ 在当前 sigma 调用 D_theta
      ▼
x_hat → 计算斜率 (y - x_hat) / sigma
      │ 数值积分器更新 y，并降低 sigma
      ▼
重复上述过程 → 到达干净端点 → 反归一化动作 → 滚动执行
```

采样时 sigma 递减，因此 `delta_sigma = sigma_next - sigma` **通常为负数**。正斜率乘以负步长，状态就沿相反方向移动；不需要再凭直觉额外加一个负号。

这里的方向是**概率流 ODE 的向量场**。虽然前向公式写成 `x_0 + sigma * epsilon`，也不能把生成路径理解为“已知某个 x_0，沿同一个固定 epsilon 一直减回去”。采样时每一步都重新估计 x_hat，方向也会变化。

## 5. Euler 与 Heun：同一个方向场，两种走法

记当前点为 `(y, sigma)`，下一噪声等级为 `sigma_next`，步长 `h = delta_sigma < 0`。

### Euler：只看起点斜率

$$
d_0=d(y,\sigma),\qquad
\boxed{y_{\mathrm{next}}=y+h\,d_0.}
$$

直觉：用起点切线线性外推到下一噪声等级；这一段里即使方向在弯，也暂时按起点方向走。

这是**一阶方法**：每个区间通常调用一次去噪器，计算便宜，但大步长时更容易偏离弯曲的轨迹。

### Heun：先预测终点，再平均两端斜率

$$
y_{\mathrm{temp}}=y+h\,d_0,\qquad
d_1=d(y_{\mathrm{temp}},\sigma_{\mathrm{next}}).
$$

直觉：先做一次 Euler 预测，再在这个**临时终点**重新调用网络，计算那里可能出现的斜率；它不是真实已知的终点。

$$
\boxed{y_{\mathrm{next}}=y+h\,\frac{d_0+d_1}{2}.}
$$

直觉：用起点与预测终点斜率的平均值，重新从原来的 y 出发更新，更好地反映这段区间内方向的变化。

这是**二阶方法**。方向场足够光滑、步长适当时，Heun 通常比 Euler 积分误差小；但对不准确的网络、很大的步长或不光滑的场，**不保证任何情况下都更准确**。

### 一个标量数值例子

只为演示积分计算，假设玩具方向场 `d(y,sigma)=sigma*y`，当前 `y=2、sigma=1`，下一点 `sigma_next=0.5`，所以 `h=-0.5`。这不是某个真实策略网络的方向场。

| 计算 | 数值 | 含义 |
|---|---|---|
| 起点斜率 | `d0 = 1 × 2 = 2` | 两种方法共用 |
| Euler 更新 / Heun 临时终点 | `2 + (-0.5) × 2 = 1` | Euler 到这里结束；Heun 继续 |
| 临时终点斜率 | `d1 = 0.5 × 1 = 0.5` | 在预测出来的状态上评估 |
| Heun 修正 | `2 + (-0.5) × (2+0.5)/2 = 1.375` | 用平均斜率，从原状态 2 重新更新 |

这个玩具 ODE 的真实终点约为 `1.3746`，因此本例 Heun 更接近。它不是“在临时结果 1 上再走一整步”，也不是预先知道了真实终点。

### 网络调用数与 sigma=0 的收尾

Heun 在普通区间通常需要**两次网络调用**：一次在起点，一次在 Euler 临时终点。比较速度时应比较网络调用次数（NFE），不能只比较循环次数。

最后一段从正的 sigma 降到 0 时，不能在终点使用 `(y-D)/sigma`，`ln(sigma)` 也无法直接计算。因此常用起点斜率做 Euler 收尾：

$$
y_{\mathrm{final}}=y+(0-\sigma)\frac{y-D_\theta(y;\sigma)}{\sigma}
=D_\theta(y;\sigma).
$$

直觉：最后一步直接落到当前的干净估计，**不在 sigma=0 重新调用网络算斜率**。

EDM 的 ODE 表达也能搭配其他兼容的数值求解器，不只限于 Euler 和 Heun。随机采样变体还可在部分步骤临时提高噪声再去噪，本文不展开其超参数。

## 6. Karras Noise Schedule：把有限步数用在合适的位置

$$
\boxed{\sigma_i=\left[\sigma_{\max}^{1/\rho}
+\frac{i}{N-1}\left(\sigma_{\min}^{1/\rho}-\sigma_{\max}^{1/\rho}\right)\right]^\rho,
\quad i=0,\ldots,N-1.}
$$

直觉：在 `sigma^(1/rho)` 空间均匀取点，再映射回 sigma，而非直接把 sigma 等分。

| 参数 | 含义 |
|---|---|
| `sigma_max` | 起始高噪声尺度，与初始化幅度匹配 |
| `sigma_min` | 结束前的最小正噪声尺度 |
| `N` | 从 sigma_max 到 sigma_min 的正噪声节点数，要求至少为 2 |
| `rho` | 控制节点分配的弯曲程度，常用经验值如 7 |

`rho=1` 就是 sigma 均匀划分；常用 `rho>1` 在低噪声区域使用更小的绝对间隔，因为不同尺度下方向变化和误差敏感程度并不相同。它旨在**更合理地分配有限采样预算**，不是 rho 越大越好，也没有固定理论最优值。

标准做法是在这些正节点后**额外追加 sigma=0**。因此这里 N 个正节点对应 N 个更新区间；若普通区间用 Heun、最后用 Euler，通常需要 `2N-1` 次去噪器调用。

动作任务的 sigma 范围应与动作归一化、训练覆盖和噪声尺度匹配，不应直接照搬原图像任务的参数。

## 7. DDPM、DDIM、EDM 对比

下面按常见 epsilon 版 DDPM / DDIM，以及本文 EDM 配置比较；各框架还有其他输出参数化和采样变体。

| 对比项 | DDPM | DDIM | EDM |
|---|---|---|---|
| 前向加噪 | `x_t=√alpha_bar_t*x_0+√(1-alpha_bar_t)*epsilon`：缩放信号并加噪 | 与 DDPM 相同的加噪边缘分布，可复用训练 | `y=x_0+sigma*epsilon`：保持信号幅度、加可变尺度噪声 |
| 时间 / 噪声参数 | 通常用离散等级 t 和 beta 表 | 从训练时间表选取离散等级 | 直接用连续噪声尺度 sigma |
| 网络预测目标 | 常预测 epsilon，亦有 x0 / v 版本 | 通常复用原模型的预测目标 | 完整 D 输出干净估计，内部 F 输出预条件残差 |
| 反向思路 | 离散马尔可夫反向转移，按均值与方差采样 | 按选定时间点之间的公式更新，eta 控制随机性 | 构造概率流 ODE 方向场并积分，也有随机变体 |
| 能否少步 / 跳步 | 原相邻步公式不能只改循环跳步；重间隔需匹配更新 | 可直接在选定时间点之间更新 | 选择有限 sigma 节点和求解步长，不受固定相邻 t 限制 |
| 采样器 / 积分方式 | 常见祖先式随机采样 | DDIM 更新；eta=0 为确定性路径 | 常用 Euler、Heun，也可用其他兼容求解器 |

**DDIM 也能联系到概率流 ODE 的离散化。** 二者共同点是能少步生成，但 EDM 的讨论还涵盖噪声坐标、预条件、训练分布与损失权重；它们不是两个互不相关的原理，也不是完全相同的方法。

EDM 不是保证“直接把 DDPM 的 scheduler 改个名字就能换好全部方案”。已有模型可在正确的尺度 / 输出转换下适配 EDM 式采样；若要采用整套新的预条件训练参数化，通常需要相应训练或严格等价的包装。

## 8. 八股面试题

| 问题 | 精炼回答 |
|---|---|
| 1. EDM 是什么？核心思想是什么？ | 梳理并改进扩散模型的设计空间，把噪声尺度、网络预条件、训练权重、调度和积分器分开设计，再组合优化。 |
| 2. 和 DDPM、DDIM 有什么区别？ | DDPM 常写成离散随机反向转移，DDIM 用兼容原训练的跨时间点更新；EDM 常用连续 sigma、干净去噪器和 ODE 积分，并优化训练参数化。 |
| 3. 前向公式是什么？ | `y=x_0+sigma*epsilon`；干净动作加上标准差为 sigma 的高斯噪声，不额外衰减动作信号。 |
| 4. 网络预测什么？ | 完整去噪器 D 预测干净动作估计 x_hat；内部 F 输出经预条件定义的残差，不直接预测下一状态。 |
| 5. 为什么需要预条件器？ | 不同噪声等级的数值尺度差异很大；预条件使内部网络的输入和目标尺度更稳定，便于训练。 |
| 6. c_skip、c_in、c_out 有什么作用？ | 分别控制输入直接通路、内部输入缩放、残差输出缩放；系数由 sigma 和 sigma_data 决定，不是学习的置信度。 |
| 7. ODE 斜率怎么计算？ | `d=(y-D(y;sigma))/sigma`；由当前带噪状态与干净估计计算，不是网络直接输出，采样步长通常为负。 |
| 8. Euler 和 Heun 有什么区别？ | Euler 只用起点斜率；Heun 先 Euler 预测临时终点，再平均起点与临时终点斜率，分别是一阶、二阶方法。 |
| 9. Heun 为什么通常更准？ | 它考虑了区间内斜率的变化；但终点是预测值，网络误差和步长仍会影响结果，不保证总是优于 Euler。 |
| 10. Karras 调度是什么？为什么需要？ | 在 sigma^(1/rho) 空间等距取点，改善不同噪声区间的预算分配；rho 是经验超参数。 |
| 11. 为什么能用较少步数？ | 更合适的噪声节点、更稳定的去噪器与较高阶积分能降低有限预算下的误差；仍需迭代，且要算 NFE 与任务成功率。 |
| 12. 与 DDIM 跳步的本质区别？ | DDIM 常以原离散时间表的跨点公式呈现；EDM 显式以连续 sigma 建立方向场并选择积分器，还配套训练设计。二者可有 ODE 联系，不能把区别说成一个连续、另一个绝对不能连续。 |

## 9. 一句话总结 EDM

**EDM 用连续 sigma 描述噪声，以预条件网络估计干净动作，再通过合理的噪声节点与数值积分，从高斯动作噪声多步走向干净动作块。**
